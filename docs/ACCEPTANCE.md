# Транслифт — приёмка по ТЗ

Сценарий демонстрации заказчику по разделу ТЗ «Проверка и критерии приёмки».

Тот же сценарий проверяет автотест `backend/test/acceptance.e2e-spec.ts`:

```bash
pnpm --filter backend test:e2e
```

## Подготовка

- [ ] Сервер развёрнут по [DEPLOY.md](DEPLOY.md), открывается по HTTPS.
- [ ] Заказчик дал контрольный набор данных: не менее двух объектов **разных типов монтажа**, документы, фото, тестовых пользователей.
- [ ] Заведены тестовые пользователи: администратор, руководитель, бригадир, сотрудник финансов.
- [ ] Бригадир открыл приложение **на своём смартфоне** и установил его на экран («Установите Транслифт на телефон»).

## Критерии

| №   | Критерий из ТЗ                                                    | Как показать                                                                                                                                 | Где в приложении                                                                               |
| --- | ----------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| 1   | Администратор создаёт объект и выбирает один из двух шаблонов     | «Объекты» → «Добавить объект». Создать объект «Замена лифта» и объект «Новостройка»                                                          | Объекты → карточка объекта, вкладка «Ход работ» показывает этапы своего шаблона                |
| 2   | Назначает бригаду                                                 | В форме объекта выбрать бригаду (или «Изменить» в карточке)                                                                                  | Бригадиру приходит уведомление «Вам назначен объект», объект появляется у него в «Мои объекты» |
| 3   | Бригадир в браузере смартфона отмечает этап с фото и комментарием | С телефона: «Мои объекты» → объект → «Отметить этап» → «Камера» → комментарий → «Отметить этап»                                              | Без фото кнопка неактивна, если фото для этапа обязательно                                     |
| 4   | Руководитель видит изменение процента и историю                   | Под руководителем: карточка объекта — процент, этап с датой, автором, комментарием и фото; вкладка «История»; «Сводка» → «Последние отметки» | Процент берётся из справочника этапов                                                          |
| 5   | Создаётся рекламация                                              | Карточка объекта → «Рекламации» → «Рекламация»: поставщик, причина, описание; добавить фото, комментарий, сменить статус                     | Реестр: раздел «Рекламации»                                                                    |
| 6   | Заполняются финансовые поля и правильно считается остаток         | Под финансистом: карточка объекта → «Финансы» → заполнить суммы → «Сохранить»                                                                | Остаток = стоимость для заказчика (или сумма договора) − оплата. Бригадир вкладку не видит     |
| 7   | Формируются индивидуальный и сводный отчёты с выгрузкой в Excel   | Карточка объекта → «Отчёт» (период) → .xlsx; «Отчёты» → «Сводный отчёт» → .xlsx; «Отчёт генподрядчику» по договору                           | Файлы открываются в Excel                                                                      |
| 8   | Данные доступны после повторного входа                            | «Профиль» → «Выйти из системы» → войти снова                                                                                                 | Всё введённое на месте                                                                         |

## Что согласовать до демонстрации

Эти решения приняты без ответа заказчика и могут меняться (подробнее в [PLAN.md](PLAN.md), раздел «Решения без ответа заказчика»):

- этапы и проценты шаблона «Монтаж в новостройке»;
- формула остатка задолженности;
- образец Excel отчёта генподрядчику; сейчас используется форма ФКР из демоверсии;
- пороги «Требуют внимания».

## Передача (после 100% оплаты)

- [ ] Настроены ежедневные резервные копии и их перенос с сервера.
